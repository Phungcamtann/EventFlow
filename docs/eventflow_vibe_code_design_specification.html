Kiến Trúc Kỹ Thuật 3 Lớp (Monolith MVC-Inspired Architecture)

Ứng dụng mô hình kiến trúc Monolith 3 lớp gọn nhẹ, độc lập và bảo mật cao, đảm bảo vận hành ổn định trên môi trường Apache/PHP 8.2 + MySQL chuẩn tại UEH:

1

Presentation Layer (Giao diện)

Bootstrap 5.3 + Tailwind Utility + Vanilla ES6 JS. Hỗ trợ responsive đa kích thước màn hình (Mobile ≥ 44px touch target, Tablet, Desktop). Sử dụng kỹ thuật AJAX AbortController cho tìm kiếm thời gian thực và DOM optimistic updates cho điểm danh tức thì.

Templates: /app/modules/*/views/*.php
2

Application Layer (Nghiệp vụ)

PHP 8.2 Monolith với mô hình Service/Action. Xác thực qua PHP Native Session, CSRF Token chống tấn công giả mạo, Middleware RBAC 3 tầng phân định quyền hạn, giải phóng Session Lock bằng session_write_close() cho các tiến trình polling ngầm.

Services: /app/modules/*/services/*.php
3

Data Layer (Dữ liệu)

MySQL 8.0 InnoDB với 11 bảng quan hệ chuẩn hóa 3NF. Ràng buộc toàn vẹn khóa ngoại (Foreign Keys), cơ chế khóa dòng SELECT ... FOR UPDATE bảo vệ hạn ngạch chỗ đăng ký, kết nối qua PDO Prepared Statements chống SQL Injection 100%.

Database: /app/database/connection.php

Thiết Kế Cơ Sở Dữ Liệu Quan Hệ (11 Bảng Chuẩn Hóa 3NF)

Hệ thống được chuẩn hóa toàn diện từ 7 bảng ban đầu lên 11 bảng chuẩn hóa 3NF, mô hình hóa chính xác cơ cấu tổ chức 4 phòng ban và quy trình tuyển dụng thực tế của BELL CLUB UEH.

1. Vai trò Hệ thống (Role.RoleName):

'admin' 'clubmanager' 'clubmember' 'participant'

2. Chức danh Nội bộ (Club_Member.MemberRole):

'President' 'Vice President' 'Head' 'Vice Head' 'Member'

3. Trạng thái Sự kiện (Event.Status):

'draft' 'upcoming' 'open' 'closed' 'ongoing' 'finished' 'cancelled'

Danh Mục 11 Bảng Quan Hệ Chuẩn Hóa

1. Role

Vai trò tài khoản hệ thống (admin, clubmanager, clubmember, participant).

2. Account

Tài khoản cá nhân, bổ sung SĐT, Chuyên ngành, Khóa (K48-K52), cờ đổi mật khẩu.

3. Club

Hồ sơ câu lạc bộ (BELL Club UEH: Tầm nhìn, Sứ mệnh, Fanpage, Địa chỉ).

4. Department (MỚI · UAT 05)

4 phòng ban chuyên môn: Human Resources, Specialist, Communications, External Relations.

5. Club_Member (NÂNG CẤP)

Liên kết Account & Department, vai trò nội bộ (President, VP, Head, Vice Head, Member).

6. Event (NÂNG CẤP · UAT 19)

Quản lý sự kiện, State Machine 7 trạng thái, giờ mở ĐK, ràng buộc min 2 BĐH.

7. Event_Staff (MỚI · UAT 08, 11)

Phân công BTC & Cán bộ hỗ trợ sự kiện. Chỉ người được phân công mới có quyền điểm danh.

8. Event_Registration (NÂNG CẤP · UAT 02)

Đăng ký tham gia: Hỗ trợ cả Thành viên đã đăng nhập và Khách vãng lai (Guest).

9. Attendance (NÂNG CẤP · UAT 17)

Ghi nhận điểm danh có lưu nhân sự thực hiện (CheckedBy), trạng thái Present/Absent.

10. Recruitment_Campaign (MỚI · UAT 02, 09)

Đợt tuyển quân mới của CLB (Ngày bắt đầu, hạn nộp, chỉ tiêu, trạng thái Mở/Đóng).

11. Recruitment_Application (MỚI · UAT 02, 09)

Hồ sơ ứng tuyển của sinh viên: Chọn phòng ban, nộp CV PDF, lịch phỏng vấn & trigger cấp tài khoản.

-- ============================================================================
-- EVENTFLOW DATABASE SCHEMA & SEED DATA (BLUEPRINT V2.0)
-- Đơn vị: CLB Tiếng Anh Sinh Viên UEH (BELL CLUB UEH)
-- Chuẩn hóa: 11 Bảng Quan Hệ 3NF + Foreign Keys + Composite Indexes

CREATE DATABASE IF NOT EXISTS eventflow_db
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

USE eventflow_db;

-- ----------------------------------------------------------------------------
-- 1. BẢNG ROLE (Vai trò hệ thống cấp cao)
-- ----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS Role (
    RoleID INT AUTO_INCREMENT PRIMARY KEY,
    RoleName VARCHAR(50) NOT NULL UNIQUE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ----------------------------------------------------------------------------
-- 2. BẢNG ACCOUNT (Tài khoản người dùng toàn hệ thống)
-- ----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS Account (
    AccountID INT AUTO_INCREMENT PRIMARY KEY,
    Email VARCHAR(100) NOT NULL UNIQUE,
    PasswordHash VARCHAR(255) NOT NULL,
    FullName VARCHAR(100) NOT NULL,
    StudentCode VARCHAR(20) NULL UNIQUE,
    Phone VARCHAR(20) NULL,
    Cohort VARCHAR(10) NULL,              -- K48, K49, K50, K51, K52
    Major VARCHAR(100) NULL,              -- Chuyên ngành đào tạo tại UEH
    AvatarUrl VARCHAR(255) NULL,
    RoleID INT NOT NULL,
    PasswordMustChange TINYINT(1) NOT NULL DEFAULT 0, -- 1 khi cấp tự động Ueh@
    IsActive TINYINT(1) NOT NULL DEFAULT 1,
    CreatedAt DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_account_role FOREIGN KEY (RoleID) REFERENCES Role(RoleID)
        ON UPDATE CASCADE ON DELETE RESTRICT,
    INDEX idx_account_search (FullName, StudentCode, Email)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ----------------------------------------------------------------------------
-- 3. BẢNG CLUB (Thông tin Câu Lạc Bộ Tiếng Anh)
-- ----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS Club (
    ClubID INT AUTO_INCREMENT PRIMARY KEY,
    ClubName VARCHAR(150) NOT NULL,
    ShortName VARCHAR(50) NOT NULL DEFAULT 'BELL UEH',
    Description TEXT NOT NULL,
    Vision TEXT NULL,
    Mission TEXT NULL,
    LogoUrl VARCHAR(255) NULL,
    CoverUrl VARCHAR(255) NULL,
    Email VARCHAR(100) NOT NULL,
    Phone VARCHAR(20) NOT NULL,
    FacebookUrl VARCHAR(255) NULL,
    Address VARCHAR(255) NOT NULL DEFAULT 'UEH Cơ sở B - 279 Nguyễn Tri Phương, Q.10, TP.HCM',
    CreatedAt DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ----------------------------------------------------------------------------
-- 4. BẢNG DEPARTMENT (Phòng ban trực thuộc CLB - MỚI · UAT 05)
-- ----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS Department (
    DepartmentID INT AUTO_INCREMENT PRIMARY KEY,
    ClubID INT NOT NULL,
    DepartmentName VARCHAR(100) NOT NULL,
    DepartmentCode VARCHAR(20) NOT NULL,  -- HR, SPEC, COMS, ER
    Description TEXT NOT NULL,
    KeyActivities TEXT NULL,
    OrderIndex INT NOT NULL DEFAULT 1,
    CreatedAt DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_department_club FOREIGN KEY (ClubID) REFERENCES Club(ClubID)
        ON UPDATE CASCADE ON DELETE CASCADE,
    UNIQUE KEY uk_club_dept_code (ClubID, DepartmentCode)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ----------------------------------------------------------------------------
-- 5. BẢNG CLUB_MEMBER (Thành viên CLB & Phân quyền nội bộ tầng 2)
-- ----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS Club_Member (
    ClubMemberID INT AUTO_INCREMENT PRIMARY KEY,
    ClubID INT NOT NULL,
    AccountID INT NOT NULL,
    DepartmentID INT NULL,                -- Nullable đối với President/Vice President
    MemberRole ENUM('President', 'Vice President', 'Head', 'Vice Head', 'Member') NOT NULL DEFAULT 'Member',
    Status ENUM('Active', 'Inactive') NOT NULL DEFAULT 'Active',
    JoinedDate DATE NOT NULL,
    Bio TEXT NULL,
    CreatedAt DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_member_club FOREIGN KEY (ClubID) REFERENCES Club(ClubID)
        ON UPDATE CASCADE ON DELETE CASCADE,
    CONSTRAINT fk_member_account FOREIGN KEY (AccountID) REFERENCES Account(AccountID)
        ON UPDATE CASCADE ON DELETE CASCADE,
    CONSTRAINT fk_member_department FOREIGN KEY (DepartmentID) REFERENCES Department(DepartmentID)
        ON UPDATE CASCADE ON DELETE SET NULL,
    UNIQUE KEY uk_club_account (ClubID, AccountID)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ----------------------------------------------------------------------------
-- 6. BẢNG EVENT (Sự kiện CLB với State Machine 7 trạng thái)
-- ----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS Event (
    EventID INT AUTO_INCREMENT PRIMARY KEY,
    ClubID INT NOT NULL,
    Title VARCHAR(200) NOT NULL,
    Description TEXT NOT NULL,
    Location VARCHAR(255) NOT NULL,
    StartTime DATETIME NOT NULL,
    EndTime DATETIME NOT NULL,
    RegistrationStartTime DATETIME NOT NULL,
    RegistrationDeadline DATETIME NOT NULL,
    MaxCapacity INT NULL,                 -- NULL = Không giới hạn
    CurrentParticipants INT NOT NULL DEFAULT 0,
    MinStaffRequired INT NOT NULL DEFAULT 2, -- Ràng buộc tối thiểu 2 BĐH/Cán bộ
    BannerUrl VARCHAR(255) NULL,
    Status ENUM('draft', 'upcoming', 'open', 'closed', 'ongoing', 'finished', 'cancelled') NOT NULL DEFAULT 'draft',
    CreatedBy INT NOT NULL,
    CreatedAt DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UpdatedAt DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT fk_event_club FOREIGN KEY (ClubID) REFERENCES Club(ClubID)
        ON UPDATE CASCADE ON DELETE CASCADE,
    CONSTRAINT fk_event_creator FOREIGN KEY (CreatedBy) REFERENCES Account(AccountID)
        ON UPDATE CASCADE ON DELETE RESTRICT,
    INDEX idx_event_dates (StartTime, EndTime, RegistrationDeadline),
    INDEX idx_event_status (Status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ----------------------------------------------------------------------------
-- 7. BẢNG EVENT_STAFF (Phân công cán bộ & Cấp quyền điểm danh - MỚI · UAT 08, 11)
-- ----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS Event_Staff (
    EventStaffID INT AUTO_INCREMENT PRIMARY KEY,
    EventID INT NOT NULL,
    AccountID INT NOT NULL,
    StaffRole ENUM('Organizer', 'Checkin_Lead', 'Support', 'MC') NOT NULL DEFAULT 'Support',
    AssignedBy INT NOT NULL,
    AssignedAt DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_staff_event FOREIGN KEY (EventID) REFERENCES Event(EventID)
        ON UPDATE CASCADE ON DELETE CASCADE,
    CONSTRAINT fk_staff_account FOREIGN KEY (AccountID) REFERENCES Account(AccountID)
        ON UPDATE CASCADE ON DELETE CASCADE,
    CONSTRAINT fk_staff_assigner FOREIGN KEY (AssignedBy) REFERENCES Account(AccountID)
        ON UPDATE CASCADE ON DELETE RESTRICT,
    UNIQUE KEY uk_event_account_staff (EventID, AccountID)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ----------------------------------------------------------------------------
-- 8. BẢNG EVENT_REGISTRATION (Đăng ký sự kiện - Thành viên & Khách vãng lai · UAT 02)
-- ----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS Event_Registration (
    RegistrationID INT AUTO_INCREMENT PRIMARY KEY,
    EventID INT NOT NULL,
    AccountID INT NULL,                   -- Null nếu là khách vãng lai (Guest)
    RegistrationType ENUM('Member', 'Guest') NOT NULL DEFAULT 'Member',
    GuestName VARCHAR(100) NULL,
    GuestEmail VARCHAR(100) NULL,
    GuestPhone VARCHAR(20) NULL,
    GuestStudentCode VARCHAR(20) NULL,
    Status ENUM('Registered', 'Cancelled') NOT NULL DEFAULT 'Registered',
    RegisteredAt DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_registration_event FOREIGN KEY (EventID) REFERENCES Event(EventID)
        ON UPDATE CASCADE ON DELETE CASCADE,
    CONSTRAINT fk_registration_account FOREIGN KEY (AccountID) REFERENCES Account(AccountID)
        ON UPDATE CASCADE ON DELETE CASCADE,
    INDEX idx_reg_event_account (EventID, AccountID),
    INDEX idx_reg_event_guest (EventID, GuestStudentCode)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ----------------------------------------------------------------------------
-- 9. BẢNG ATTENDANCE (Điểm danh tham gia sự kiện · UAT 17)
-- ----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS Attendance (
    AttendanceID INT AUTO_INCREMENT PRIMARY KEY,
    EventID INT NOT NULL,
    RegistrationID INT NOT NULL,
    CheckinTime DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CheckedBy INT NOT NULL,               -- Nhân sự thực hiện check-in (từ Event_Staff)

    Notes VARCHAR(255) NULL,
    CONSTRAINT fk_attendance_event FOREIGN KEY (EventID) REFERENCES Event(EventID)
        ON UPDATE CASCADE ON DELETE CASCADE,
    CONSTRAINT fk_attendance_registration FOREIGN KEY (RegistrationID) REFERENCES Event_Registration(RegistrationID)
        ON UPDATE CASCADE ON DELETE CASCADE,
    CONSTRAINT fk_attendance_staff FOREIGN KEY (CheckedBy) REFERENCES Account(AccountID)
        ON UPDATE CASCADE ON DELETE RESTRICT,
    UNIQUE KEY uk_attendance_registration (RegistrationID)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

Đặc Tả Code Hàm Kiểm Tra Quyền (Middleware Helper)

<?php
// /app/includes/auth_guard.php - EventFlow 3-Tier RBAC Guardrail

/**
 * Tầng 1: Kiểm tra đăng nhập bắt buộc
 */
function require_auth(): array {
    if (session_status() === PHP_SESSION_NONE) {
        session_start();
    }
    if (empty($_SESSION['account_id'])) {
        header('Location: /app/modules/auth/login.php?redirect=' . urlencode($_SERVER['REQUEST_URI']));
        exit;
    }
    // Ràng buộc tân thành viên phải đổi mật khẩu lần đầu (Ueh@)
    if (!empty($_SESSION['password_must_change']) && basename($_SERVER['PHP_SELF']) !== 'profile.php' && basename($_SERVER['PHP_SELF']) !== 'logout.php') {
        header('Location: /app/modules/auth/profile.php?notice=password_must_change');
        exit;
    }
    return $_SESSION['user'];
}

/**
 * Tầng 2: Kiểm tra chức danh Ban Điều Hành / Trưởng Phòng HR
 */
function require_club_lead(string $specificDept = null): bool {
    $user = require_auth();
    // System Admin hoặc President/Vice President luôn có quyền
    if ($user['role_name'] === 'admin' || in_array($user['member_role'] ?? '', ['President', 'Vice President'])) {
        return true;
    }
    // Trưởng phòng HR thao tác module tuyển quân
    if ($specificDept === 'HR' && ($user['dept_code'] ?? '') === 'HR' && in_array($user['member_role'] ?? '', ['Head', 'Vice Head'])) {
        return true;
    }
    http_response_code(403);
    include __DIR__ . '/../views/errors/403.php';
    exit;
}

/**
 * Tầng 3: Kiểm tra quyền điểm danh / điều hành theo từng Sự Kiện cụ thể
 */
function has_event_staff_perm(PDO $pdo, int $eventId, int $accountId): bool {
    // 1. Kiểm tra nếu là President hoặc Vice President
    $stmt = $pdo->prepare("SELECT MemberRole FROM Club_Member WHERE AccountID = ? AND Status = 'Active'");
    $stmt->execute([$accountId]);
    $role = $stmt->fetchColumn();
    if (in_array($role, ['President', 'Vice President'])) {
        return true;
    }
    // 2. Kiểm tra nếu có phân công chính thức trong Event_Staff
    $stmt = $pdo->prepare("SELECT 1 FROM Event_Staff WHERE EventID = ? AND AccountID = ?");
    $stmt->execute([$eventId, $accountId]);
    return (bool)$stmt->fetchColumn();
}

Máy Trạng Thái Sự Kiện 7 Bước (Realtime Event State Machine)

Mọi sự kiện trong hệ thống vận hành theo vòng đời 7 trạng thái chuẩn hóa, kết hợp giữa kích hoạt thủ công của Ban Điều Hành và tự động cập nhật theo mốc thời gian thực:

1. draft Bản nháp nội bộ, chưa công khai
2. upcoming Sắp mở đăng ký (Hiện Countdown)
3. open Đang mở đăng ký cho SV/Khách
4. closed Hết hạn ĐK hoặc đầy chỗ
5. ongoing Đang diễn ra (Mở bàn Check-in)
6. finished Đã kết thúc, tổng kết số liệu
7. cancelled Đã hủy, khóa toàn bộ thao tác

Quy tắc Chuyển Trạng Thái (State Transition Rules):

  • Sự kiện chỉ được chuyển từ draft sang upcoming khi đã có đủ tối thiểu 2 Cán bộ BĐH trong Event_Staff.
  • Khi đến RegistrationStartTime, hệ thống tự động kích hoạt trạng thái open.
  • Khi đến RegistrationDeadline HOẶC CurrentParticipants >= MaxCapacity, chuyển thành closed.
  • Khi đến StartTime của sự kiện, chuyển thành ongoing. Kết thúc EndTime, chuyển thành finished.

Giao Diện Lịch Sự Kiện Đa Chế Độ: Lịch Tháng (Pills) & Lịch Tuần (Timeline 07h – 22h)

Hệ thống cung cấp trải nghiệm quản lý thời gian trực quan theo chuẩn Notion Calendar (bám sát mockup đính kèm), phục vụ cả người xem công chúng và cán bộ ban tổ chức CLB:

1. Chế Độ Lịch Tháng (Month View Grid)

7 Cột: Sun → Sat

• Header điều hướng: Tên tháng năm (VD: November 2026), 2 nút mũi tên chuyển tháng < >, nút "Today" để quay về ngày hiện tại.
• Ô ngày trong tháng hiển thị số ngày ở góc trên. Phía dưới là các thanh nhãn sự kiện (Event Pills) chứa Emoji/Icon, Tên sự kiện rút gọn và nhãn danh mục/trạng thái (VD: ✨ Speaking Circle).
• Bấm vào bất kỳ thẻ sự kiện nào sẽ mở popup xem nhanh thông tin tóm tắt và nút điều hướng chi tiết.

2. Chế Độ Lịch Tuần (Week / Timeline View)

Mốc giờ 07:00 – 22:00

• Trục ngang gồm 7 cột ngày trong tuần (Mon 24, Tue 25, Wed 26 [Today], Thu 27, Fri 28...).
• Trục dọc chia khung giờ từ 07:00 đến 22:00 (bước nhảy 60 phút). Có vạch ngang màu đỏ biểu thị thời gian hiện tại (Current Time Bar) kèm đồng hồ thời gian thực (VD: 10:15 AM).
• Các khối sự kiện được tính toán vị trí và chiều cao chính xác bám theo StartTime và EndTime, có màu sắc theo phòng ban phụ trách (HR: Tím, Specialist: Xanh dương, Coms: Hồng, ER: Cam).
